## 步骤

```sh
npm i -g lark-channel-bridge
```

```sh
lark-channel-bridge run
```

第一次运行会进入扫码向导：

- 终端渲染二维码。
- 用飞书 App 扫码。
- 选择或创建 PersonalAgent 应用。
- 如果终端提示，选择本次要初始化的 agent。
- 成功后配置写入 ~/.lark-channel/config.json。
