# Agent三种设计范式

## ReAct （Reasoning + Action）

日常信息搜索、简单问答助手、客服机器人

短板：每一步都是局部最优决策，处理特别复杂、需要全局规划的任务时，容易在中间步骤忘记目标、或者反复在几个工具之间打转

## Plan-and-Execute

解耦规划和执行

**关键机制：动态重规划**

     执行完每一步都会把结果反馈给规划器，如果严重偏离，规划器会修改后续步骤、甚至插入新步骤来应对

短板：多了规划和重规划的LLM调用。延迟和成本增加。

## Reflection

在Agent完成一步或整个任务之后，加LLM评估（可以是同一个模型也可以是专门的评估模型），加一层质量保障

**变体：Reflexion**

     会生成一段具体的反思总结，记录这次失败的原因和改进建议，然后把这段总结作为额外上下文传给下一次尝试。

## ps

能用Workflow解决的问题，就不要用Agent。
