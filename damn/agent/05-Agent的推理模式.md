# Agent的推理模式

## 存在意义

让 LLM 把隐式的推理过程**显式化**，从而减少多步推理中的累积误差。

## CoT （Chain of Thought，思维链）

**两种触发方式**

1. Zero-shot CoT

   直接在prompt末尾加一句“让我们一步步思考”。

   优势：零成本，即插即用。

   缺点：推理格式和深度完全靠LLM自己发挥，不太稳定。

2. Few-shot CoT

   要在prompt里给几个带有完整推理过程的例子，让LLM照这个格式来模仿。

   优势：稳定，特别适合输出格式要求比较固定的场景。

   缺点：要提前准备高质量示例，示例本身也占用token。

**根本性局限**

纯文字推理，无法与外部世界交互。

需要有一个能在推理过程中出去拿数据、执行工具，再回来继续推理，并且这件事是原生设计的系统 -> ReAct

循环漂移、错误传播->Plan-and-Execute

规划用大模型、执行用小模型
